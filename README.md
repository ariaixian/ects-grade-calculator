# ECTS Grade Calculator

A small browser application for calculating a credit-weighted course average
using European Credit Transfer and Accumulation System (ECTS) values.

**Live demo:**
[ariaixian.github.io/ects-grade-calculator](https://ariaixian.github.io/ects-grade-calculator/)

## Portfolio role

This is an early front-end project retained as a secondary example of browser
interaction and interface experimentation. It is not a flagship research
repository.

## Use

1. Add a row for each course.
2. Enter its grade and ECTS weight.
3. Calculate the credit-weighted mean.

All calculations run locally in the browser. No course data is sent to a
server.

## Current limitations

- No automated test suite
- No selectable institutional grading scales
- No formal accessibility review
- PDF output depends on browser-loaded libraries
